# Copilot Support Ticket End-User Communications
**Prepared by:** DWP Engineer
**Date:** 2026-08-12

---

## Purpose

This document contains plain-English end-user communications for each Copilot support ticket. Each message explains the likely issue in simple terms and gives the next practical steps.

---

## Ticket 1

**User scenario:** Finance lead cannot get Copilot to summarise the Q3 board pack in SharePoint.

**End-user communication**

Copilot can sometimes take time to recognise a document in SharePoint, especially if the file was uploaded, moved, relabelled, or had its permissions changed recently. Even if you can open the file yourself, Copilot may not be ready to use it straight away.

**Next steps**

- Please confirm whether the board pack was uploaded or changed recently.
- Try again after a short wait if the file is new or was recently updated.
- If the issue continues, IT will check whether the file has a sensitivity label or permissions setting that is preventing Copilot from using it.

---

## Ticket 2

**User scenario:** New hire says Copilot in Outlook does not seem to know about recent emails.

**End-user communication**

Because your account is very new, Copilot may not yet have had enough time to catch up with your mailbox content. This is usually a short delay rather than a fault with Outlook or Copilot.

**Next steps**

- Continue using Outlook normally while the mailbox content finishes syncing and indexing.
- Try Copilot again later today or the next working day.
- If it still has no awareness of your recent emails after that, IT will check your mailbox setup and licence status.

---

## Ticket 3

**User scenario:** HR manager asked Copilot in Word to use a sensitive salary review spreadsheet and got an access message.

**End-user communication**

This message usually means Copilot is not allowed to use that spreadsheet as a source. That can happen either because your account does not have the right level of access to the file, or because the file is protected in a way that blocks Copilot from using it.

**Next steps**

- First, please check whether you can open the exact spreadsheet directly yourself.
- If you can open it, IT will then review whether a sensitivity label or protection setting is blocking Copilot from using it.
- If you cannot open it directly, access to the file will need to be reviewed with the document owner.

---

## Ticket 4

**User scenario:** Sales rep cannot get Copilot in Teams to find a client contract shared by guest link from another organisation.

**End-user communication**

Copilot is more limited with content that comes from another organisation through guest or external sharing. Even if you can open the contract through a shared link, Copilot may not be able to use that content in the same way it uses files stored inside our own Microsoft 365 environment.

**Next steps**

- Please confirm that the contract is coming from an external organisation and was shared by guest link.
- If you need Copilot to work with the document, the usual workaround is to store an approved internal copy in our own tenant, subject to the correct permissions and policy.
- IT can confirm whether this is an external-sharing limitation in your specific case.

---

## Ticket 5

**User scenario:** Copilot stopped working for the whole Finance team this morning.

**End-user communication**

Because this is affecting a whole team rather than one person, the most likely causes are a licence, client, or service-side issue rather than anything you personally changed. We need to confirm whether the required Copilot access is still in place for the affected users.

**Next steps**

- IT will first check the Finance team's Copilot and Microsoft 365 licence assignments.
- Please tell us whether the issue affects everyone in Finance or only some users, and whether it happens in all apps or only one.
- If licences and client prerequisites are correct, IT will then check for a wider Microsoft 365 service issue.

---

## Ticket 6

**User scenario:** Manager is concerned that Copilot found and summarised a file they do not remember opening.

**End-user communication**

Copilot does not need you to have opened a file before. It works from the access you already have. If you still have permission to a folder or document, Copilot may surface it even if you forgot it was there.

**Next steps**

- IT will check the permissions on the folder and file that Copilot used.
- If you should not have access to that content, the access needs to be removed from the source location.
- If the access is valid, then Copilot is behaving as designed and no product fault is indicated.

---

## Ticket 7

**User scenario:** Analyst says Copilot gives generic answers and does not appear to use internal SharePoint content.

**End-user communication**

When Copilot gives very general answers, it often means it is not grounding its response in the SharePoint content you expected. The most common reasons are that the content is not accessible to your account in the right way yet, or it has not fully indexed.

**Next steps**

- Please confirm which SharePoint files or sites you expected Copilot to use.
- Check whether you can open those documents directly yourself.
- If the files are new or were recently changed, allow some time and try again.
- If the issue continues, IT will check both access permissions and whether the content is ready for Copilot to use.

---

## Ticket 8

**User scenario:** Executive assistant cannot get Copilot in Outlook to see a shared mailbox calendar managed on behalf of a director.

**End-user communication**

Shared and delegated mailboxes do not always behave the same way as your own primary mailbox in Copilot. In many cases, Copilot can only work reliably with content that belongs directly to your own account rather than a calendar you manage on someone else's behalf.

**Next steps**

- Please confirm whether this is a delegated or shared mailbox calendar rather than your own calendar.
- IT will review whether the calendar access method is supported for the Copilot action you are trying to use.
- If this is a shared-mailbox limitation, we will advise on the closest supported workaround.
